## 1\. What is an HTML file? An HTML file is a text file that contains data for a browser to contain a website. The browser translates the data into a site when launched.

## 2\. What does a web browser like Chrome do with an HTML				 file? The browser will render the site that was created in the html file on screen. However, the underlying code would not be shown.

## 3\. What is a repository? A repo is a folder created by git on your machine to store different files and folders inside of it. They can also be created on the cloud as well.

## 4\. What does commit do, and what does push do? What is the difference? Commit is where take a and you get it ready to be pushed to the GitHub site. Think of commit As you're going to commit Something. When you push a file, the file will be pushed to the cloud. The difference is that when you commit something, you're getting it ready, but when you push something it goes out to the cloud where the public can see it or you can set it to private mode as well. One important note though: The repository must be published first period

## 5\. When you open a page, what does the screen reader say first? Where in the HTML does that come from? The screen reader when you open a web page says the name of the page and it starts reading from the top to bottom automatically in most cases. The screen reader reads from the metadata in the browser in this case the tab name toward the top of the page.
